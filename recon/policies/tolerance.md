# 对账容差规则

> 版本 v1，生效日期 2026-01-01。

## 1. 容差分档

按**我方交易额**落档，容差为绝对金额：

| 交易额区间 | 允许绝对容差 |
|---|---|
| ≤ 100.00 元 | 0.01 元（1 分） |
| 100.01 ~ 1000.00 元 | 0.05 元（5 分） |
| 1000.01 ~ 10000.00 元 | 0.10 元（1 角） |
| > 10000.00 元 | 1.00 元 |

## 2. 容差内差异的处置

差额绝对值 ≤ 对应档位容差时，**允许直接核销（AUTO_WRITEOFF），无需审批**。

核销时必须写明：
1. 差额金额与所在容差档位；
2. 是否找到可归因的具体规则原因（舍入模式差异 / 口径差异 / 无）。

⚠️ **不得为容差内差异编造归因。** 找不到具体原因时，如实记为「容差内无解释差异」。
虚构归因会污染差错类型统计，是比不归因更严重的问题。

## 3. 容差不适用的情形

以下情形即使差额在容差内，也**不得自动核销**：

- 单边账（任一侧完全缺失该笔）—— 金额可能恰好很小，但性质是缺失，不是差异；
- 币种不一致；
- 同一渠道流水号对应多笔不同金额；
- 累计退款超过订单原额；
- 存在结算合规问题。

## 4. 累计容差上限

同一对账任务内，自动核销的累计金额不得超过该任务我方合计的 **0.5%**。
超过后剩余差错一律转人工，防止用容差掩盖系统性问题。
