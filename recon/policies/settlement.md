# 结算与冻结规则

> 版本 v1，生效日期 2026-01-01。

## 1. 结算周期

| 商户 | 结算周期 | 允许垫资 |
|---|---|---|
| M001 云图科技 | T+1 | **是** |
| M002 海角零售 | T+1 | 否 |
| M003 长风教育 | T+3（协议约定） | 否 |
| M004 北岸出海 | T+1（paypal 部分周结） | 否 |
| M005 同舟平台 | T+1 | 否 |

渠道自身结算周期见 `channel_fees.md`；商户协议周期优先。

## 2. 结算冻结规则（核心）

> **商户 `allow_advance = 0`（不允许垫资）时，其结算期内存在任何未平差错，
> 该期结算单必须置为 `frozen`，不得打款。**

允许垫资的商户（`allow_advance = 1`）可在差错未平时先行结算，差错平账后补差。

## 3. 违规情形

若发现 `allow_advance = 0` 的商户在存在未平差错的期间，结算单状态已为 `paid`
（差错码 D16），属**结算合规违规**：

- 处置：**ESCALATE 转人工**，不得由自动流程处理；
- 不得通过冲正差错来「补救」已打款事实；
- 需同时冻结该商户后续结算，直至人工复核完成。

## 4. 分账

分账商户（如 M005）的结算金额按分账明细逐一计算。

**分账明细合计必须等于订单金额。** 不等时属分账比例错误（差错码 D13），
处置为冲正分账记账（REVERSAL），并重算受影响的结算单。

| 商户 | 分账方 | 比例 |
|---|---|---|
| M005 同舟平台 | S01 | 70% |
| M005 同舟平台 | S02 | 30% |

## 5. 结算金额口径

```
结算金额 = Σ(成功支付交易额 - 手续费) - Σ(成功退款金额)
```

手续费不因退款返还（见 `refund.md` §3），故退款只扣减交易额部分。
