# 方差与 pass^k：deepseek-v4-flash·v1 [v1]

同配置独立跑 **3** 次，60 条任务，temperature=0。

## 为什么先做这个

同一配置在阶段 2 跑出「需读文本 92.9%」、阶段 3 跑出「85.7%」，相差 7 个百分点；
而消融阶梯各级之间的差异也就 5~11 个点。**不知道噪声下限就解读这种差异是无效的。**

## 可靠性

| 指标 | 值 |
|---|---:|
| pass^1（单次正确率均值） | 52.2% |
| **pass^3（3 次全对）** | **21.7%** |
| fail^3（3 次全错） | 20.0% |
| 翻转率（判定不稳定） | 58.3% |
| 需读文本 pass^1 | 73.8% |
| 需读文本 pass^3 | 42.9% |

> **噪声下限约 ±7.1 个百分点。**
> 小于这个量级的消融差异不能当结论。
